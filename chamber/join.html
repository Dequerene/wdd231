NP Membership Benefits

This level is designed for nonprofit organizations and has no membership fee.

  • Community event invitations
  • Basic directory listing
  • Networking opportunities

Bronze Membership Benefits

This level is a good starting option for small businesses.

  • Business directory listing
  • Chamber newsletter updates
  • Access to selected training events

Silver Membership Benefits

This level gives businesses more promotion and participation opportunities.

  • Enhanced directory listing
  • Event discounts
  • Social media mentions
  • Training and workshop access

Gold Membership Benefits

This level provides the highest visibility and premium chamber benefits.

  • Premium directory listing
  • Homepage spotlight opportunities
  • Priority event promotion
  • Special event discounts
  • Business leadership networking
